# Búsqueda en grafos: Dijkstra y A\*

Interfaz gráfica en Tkinter que visualiza, paso a paso, los algoritmos de búsqueda de Dijkstra y A\* sobre un grafo ponderado. Muestra el recorrido de los nodos y la ruta encontrada.

Práctica de la materia de Inteligencia Artificial, ESCOM-IPN, desarrollada con apoyo de herramientas de IA.

## Qué incluye

- **Dijkstra** para encontrar la ruta de menor costo, con cola de prioridad (`heapq`).
- **A\*** con una heurística para guiar la búsqueda y reducir nodos explorados.
- **Animación** del recorrido, para comparar cómo explora cada algoritmo.

## Requisitos

- Python 3.9 o superior, con soporte para Tkinter.
- No requiere librerías externas.

## Uso

```bash
python busqueda_dijkstra_astar.py
```
